THE LAW (j2r-codegen/src/lib.rs, resolve_virtual_target)
--------------------------------------------------------
The generated crate is a closed world. A receiver statically typed as
the user class C carries, at run time, exactly C plus its transitive
user subclasses through super_name links. For every possible receiver
the walk mirrors j2r_runtime::invoke_virtual level for level:
  1. compiled method at the level (ClassPlan::method — the same
     source the registry match arms come from),
  2. natives row at the level (natives::lookup_exact; user levels
     included — the order user-method-then-native is the law and it
     holds even for a user class shadowing a builtin name),
  3. the parent: user super_name (java/lang/Object default), then
     builtin::builtin_parent_of.
Some(target) only when EVERY possible receiver's walk lands on the
same single target; the emitter then places the direct call in the
InvokeSpecial forms (Option::Some(&__r)) — the frame refresh, the
pop_ref NPE law and the j2r_try! wrap are byte-identical. None keeps
the dynamic path: diverging walks, walks that would die the internal
Error, and — slice 1's conservative gate — ALL interface-typed sites
(the implementor closure is a different receiver set; interface
defaults are not on the runtime super-chain walk), plus every builtin
and array declared type (open receiver sets).
