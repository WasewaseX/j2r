THE LAW (j2r-codegen/src/lib.rs)
--------------------------------
virtual_receiver_set — the closed-world receiver set of a site:
  * user CLASS declared: the class + transitive user subclasses
    (super_name edges — slice 1's set, extracted);
  * user INTERFACE declared: the implementor closure — every user class
    whose subtype closure reaches the interface through the user tables
    (super_name + interfaces edges, transitively; the same traversal
    the runtime's is_ref_subtype makes over the generated parents
    table, minus the builtin edges that provably cannot contribute:
    builtin tables never name user classes). Interfaces themselves are
    never receivers: an interface cannot be instantiated and lambdas
    targeting USER interfaces are a loud compile error
    (lambda.rs SUPPORTED_INTERFACES covers the M3 builtin set only —
    a builtin closure's class IS its interface, which is why
    builtin-interface sites keep the fully dynamic path).
  * empty closure -> None (the site can only NPE; the dynamic path
    already does that faithfully).
resolve_virtual_target — unchanged law: fold to ONE direct target only
when EVERY receiver's walk lands on the same target. The slice-1
interface gate is superseded: interface sites resolve through the
closure now.
resolve_vtable — the polymorphic residue's codegen-time VTABLE:
  per-receiver arms grouped by identical walk target
  (VtableArm { classes, target }), first-seen declaration order
  (byte-stable emission); a receiver whose walk would die the internal
  Error gets NO arm — the emitted `_` fallback re-enters the FULL
  dynamic walk and dies it identically; any class outside the closed
  world also falls back, byte-identically. Planned only when the direct
  fold would NOT fire and >= 2 distinct groups exist.
object_class (j2r-runtime/src/object.rs, root-exported) — the concrete
class of a heap object: the SAME jclass field the dispatch walk starts
from, cloned out under the heap lock (one Arc incref).
Emitter (emit.rs InvokeVirtual/InvokeInterface, shared by the
single-crate and partitioned paths): direct fold first; else the
vtable match —
    let __v = {
        let __cls = ::j2r_runtime::object_class(&__r);
        match &*__cls {
            "Cat" => ...direct user call...,
            "Dog" => ...direct user call...,
            _     => ...invoke_virtual (the dynamic walk)...,
        }
    };
  the frame refresh, the pop_ref NPE law and the j2r_try! wrap ride
  the same code for every arm (fault_pc unchanged). typed.rs keeps the
  dynamic path (--emit-typed is non-default; the slice-1 precedent).
