THE FOUR ITEMS

1. H-1 `j2r cfg-report --surface` — the sorted, deduplicated JDK member
   surface the inputs need, each site marked ok/MISSING by the
   compiler's OWN resolution functions (resolve_call, validate_virtual,
   resolve_field, builtin_is_instantiable, the ANewArray element law —
   the report calls the same code the gate calls, so it can never
   disagree with a later real compile). New module
   crates/j2r-codegen/src/surface.rs: Site {owner, name, desc, kind}
   over Call/Field/Instantiate/ClassRef — the walk covers all five
   invoke shapes, all four field shapes, new, anewarray/checkcast/
   instanceof, ldc Class constants AND the exception-table catch types
   (the World$1 shape the owner hit). Exit 0 when clean, 1 when any
   site is MISSING.

2. H-2 `--surface --diagnostics` — collect-all-then-fail: prints only
   the MISSING rows and exits 1. THE ENABLER: compile() was split into
   compile() (the unchanged hard gate: verify -> validate -> main-class,
   exact original order preserved) and compile_unchecked() (parse/plan
   only) — the surface walk runs on the UNCHECKED program, so it sees
   PAST the first unsupported shape instead of dying on it. Emission
   still goes through compile() only.

3. H-3 the partition runner's exception-table law — already satisfied
   by PartitionCatch (external-B2/O5, k=2) — extended: the B-wave's
   Externals fixture joins the partition set at k=2 (an
   exception-table-bearing class whose <clinit> also catches + the JLS
   12.4.2 launcher ensure line through the PARTITIONED main template).
   partition_suite now 8 stems, PASS.

4. H-4 / O6 the reference charset pin — run_java_program (the `j2r
   test` reference channel) now passes -Dfile.encoding=UTF-8 itself
   instead of inheriting the ambient locale. The owner's five phantom
   failures (BigJson, CharClassify, StringExt, StringIoSemantics, Utf16
   writing ASCII `?` for non-ASCII under a C locale) are structurally
   impossible from this harness path forward.

HONESTY NOTES

- The surface walk covers the jbox2d class of gaps (JDK member
  resolution). It does NOT model the partitioned-only failure class
  (B2's E0433) or emission-time shapes — the registered --partition-2
  runner variant + the exception-table fixture law cover those.
- The report's `ok` means "the compiler's resolution law accepts the
  site" — the same contract as a successful compile; runtime-surface
  depth (e.g. a native that throws a loud gap) is a different axis and
  stays the natives table's business.
- compile()/compile_unchecked() split touches the pipeline's public
  shape; the full battery re-ran green (diff 112/0, cfg 0, partition
  8/8, units 561/0) and the gate order inside compile() is preserved
  byte-for-byte.
