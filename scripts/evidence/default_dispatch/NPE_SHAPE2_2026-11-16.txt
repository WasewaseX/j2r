THE MESSAGE-GRAMMAR LAWS the matrix pins:
  1. Action-first grammar: "Cannot <action>" where action ∈ {invoke
     "<class>.<m>(<desc>)", read the array length, read field "<name>",
     store to <elem> array, ...}; the class in the invoke action is the
     RECEIVER's static class (S3: String, not java/lang/String — the
     erased name), the desc is the real descriptor.
  2. The CAUSE grammar has exactly two javac-reachable forms:
     - the producer chain: "the return value of
       \"<producer-class>.<producer-m>(<erased desc>)\" is null" —
       the desc is ERASED to the erasure (Map.get(Object), not
       Map.get(Object)Object for the generic); S1/S4/S8.
     - the null local: "\"<localN>\" is null" where <localN> is the
       JVM's fallback when the LVT is ABSENT — javac without -g
       emits no LocalVariableTable, so Temurin prints the local SLOT
       index (S2/S3: slot 1; S6: slot 2). With -g the real names
       would appear; the diff_suite harness compiles WITHOUT -g, so
       the <localN> form is the oracle j2r must reproduce.
  3. The receiver's STATIC type drives the action even when the
     producer says otherwise (S1: Double.doubleValue is the unbox
     call javac wove in AFTER the get).
